# 🧮 MathiKids

اپلیکیشن آموزشی و بازی‌محور ریاضی برای کودکان

## ✨ امکانات

- 🎮 چهار عمل اصلی (جمع، تفریق، ضرب، تقسیم)
- ⭐ سیستم امتیاز و ستاره
- 🎯 بازی‌های جایزه (مار، جفت‌یاب، هدف‌زن)
- 🗣 سه زبانه (فارسی، عربی، انگلیسی)
- 🎵 صداهای تشویقی
- 🧮 ماشین حساب آموزشی
- 📊 جدول ضرب تعاملی
